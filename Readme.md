## 当前版本：

修改了GB内部ACO的相关结构：

    1. 评估函数改为了真实的目标函数值（Cost，RA）。而不是使用代理目标（最短距离）。
    2. 由于在使用真实目标函数时，GB中间断开，在decode时不能使用回溯充电。因此，修改了decode的方法，每次到达节点i都要检查是否可以到达最近的CS，如果到不了，就在节点i前插入节点i-1最近的充电站，并回到上个节点的状态继续进行。
    3. 这种方法需要运行两次，分别生成基于Cost的最优路径，基于RA的最优路径。

但是，使用真实的目标函数值后，运行时间减慢，在solomon数据集中，仅生成一个完整的路径集需要12-15s。
因此决定还是使用原来的代理目标（最短距离），只生成一条初始路径。
然后基于这条初始路径进行VNS。
